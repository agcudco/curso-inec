# Cuaderno del participante — INEC R módulos 3, 4 y 5

1. Abra el archivo `calidad_inec_modulos_3_5.Rproj` con RStudio.
2. Lea `GUIA_ESTUDIO_MODULOS_3_4_5.md`; siga los apartados 0, 3, 4 y 5.
3. Utilice exclusivamente `R/PLANTILLA_TALLER_PARA_COMPLETAR.R` como punto de partida de su código y cree scripts nuevos paso a paso.
4. Consulte las imágenes en `figuras/` para comprender el resultado visual esperado.
5. Use `actividades/ACTIVIDADES_PROPUESTAS_MODULOS_3_4_5.md` para practicar.
6. No sobrescriba `data_raw/personas_encuesta_sintetica_2026_10.csv`.

Los archivos `.R` completos del instructor y el solucionario **no se incluyen en este paquete para participantes**. Son referencias docentes que se revisarán después de cada actividad. El objetivo es construir el proyecto, no ejecutarlo entero.
