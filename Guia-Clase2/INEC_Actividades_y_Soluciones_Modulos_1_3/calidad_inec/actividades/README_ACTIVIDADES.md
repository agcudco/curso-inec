# Actividades y solucionario (módulos 1–3)

**Para participantes:** empezar por `ACTIVIDADES_PROPUESTAS_PARTICIPANTE.md` y escribir el código en `../R/ACTIVIDADES_PARA_COMPLETAR.R`, completándolo sección por sección.

**Para instructores:** consultar `SOLUCIONARIO_DOCENTE_COMENTADO.md` y `../R/SOLUCIONARIO_15_ACTIVIDADES.R` después de cada ejercicio, no al iniciar la práctica.

**Base de datos:** `../data_raw/personas_encuesta_sintetica_2026_10.csv`. El diccionario está en `../diccionario/diccionario_variables.csv`.

**Visualizaciones:** referencias en `../figuras/`. Son imágenes elaboradas con el CSV sintético para ilustrar el resultado esperado; no son capturas de un proyecto R ejecutado.

Todos los datos y controles son ejemplos docentes. No se modifica ni reescribe el CSV; las decisiones de corrección se estudian en módulos posteriores.
